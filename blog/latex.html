Creating a LaTeX powered blog inspired by LMFDB - Part 1

I had the task of creating a blog in the back of my mind for a while now. What finally got me to do it is being recently told about LMFDB. In this post I'm going to talk about the details (the first of hopefully two parts) of how I added new functionality to this site. (The code for this functionality is left as an exercise for the reader)

Before this, all the pages of this website were created manually. As it seemed to me using a site generator would've taken more time than typing the HTML by hand. This changes if I want to add a blog.

There are plenty of site generators available, but I decided to create my own. That way, it'll be easier to use and customize to my needs. At the moment, all it is is a simple python script that takes this directory structure

the content of each HTML file is clear from the directory structure.

As for including LaTeX, the simplest solution might've been using MathJax or KaTeX. I decided to pre-render the math to SVG instead, because it'll work without javascript, be faster to load (for small pages, which are likely to be all the pages of this site), and be more accessible to simpler browsers (like netsurf) where MathJax and KaTeX don't work.

The tex.db file is not necessary for the website to work, only during generation, it has all the TeX formulas in the site along with the corresponding SVG file (encoded in the row id) and the image dimensions. It works as a cache table to reduce the size and rendering time and prevents file name collisions. There's no harm in including it so I decided to keep it. Download it if you're curious.

As for creating the SVGs themselves, I'm using this latex2svg python module. It's simple enough and works perfectly.

The TeX generating each SVG is included in its alt text, so the site is perfectly viewable in a text only browser. I initially thought this wouldn't work with dark mode but then I found out about the css invert filter, so it works fine. For static sites, this, in my opinion, is the superior way to include LaTeX.
